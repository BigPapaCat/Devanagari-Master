# 📖 Devanagari Master

Learn Devanagari quickly with Devanagari Master

## 🚀 Quick Start
To prevent the cards from appearing in a random order, you **must** change this setting:

1. Import `devanagari_master.apkg` into Anki.
2. Click the **gear icon (⚙️)** next to the deck $\rightarrow$ **Options**.
3. Change **"Insertion Order"** to **Sequential**.

---

## 🗺️ How it Works
This deck uses a building-block system:
1. **Alphabet**: Learn the basic letters.
2. **Matra Key**: Learn the vowel signs.
3. **Syllables**: Practice every possible combination.

**Design**: Clean UI with Sarvam AI audio.
